## 논의로 배운 것 (대화)
- **ceux/celles로 반복 회피** + **동사 생략(ellipse)**: les Pokémon d'Eau sont bleus, **ceux de Feu [sont] rouges**… (celui/celle/ceux/celles 카드 = 8/18 학습, 자유산출 인출 실패 → 재생산 필요)
- **leur/leurs**: 소유된 명사 수에 일치 (leurs types ✅) ≠ 간접목적 대명사 leur(불변)
- **dont + 관사**: dont **le** type (whose type)
- **de type X**(게임 말투) = 관계절보다 간결
