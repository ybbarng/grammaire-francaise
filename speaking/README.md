# speaking — Q4 말하기 (2026-10~12)

프랑스어를 **실시간으로 구성해 대화를 유지**하고, **상대가 이해할 수 있는 수준으로 명료하게 전달**하는 능력을 훈련·측정한다.

## 목표 (2축)

1. **실시간 문장 구성** — 하고 싶은 말을 그 자리에서 프랑스어 문장으로 만들고, 대화를 끊지 않고 이어간다.
2. **의사소통 명료도(intelligibility)** — 완벽한 억양이 아니어도, 상대(ChatGPT)가 내 발화를 한 번에 알아듣는다.

> **범위 밖(명시)**: 원어민 수준 억양·리듬·개별 음소 정확성은 이 시스템으로 정밀 평가하지 않는다. 음성 품질은 분기 1~2회 별도 샘플링(원어민/앱)으로만 점검한다. 이유: ChatGPT transcript는 실제 음성이 아니라 **STT가 인식한 결과**이므로, 발음 정밀 채점의 근거로는 부적합하다.

## 왜 ChatGPT 앱인가

- 실시간 음성 대화 경험이 현재 가장 좋다(실제 사람과 대화하는 느낌 → 목표 2축에 직접 유효).
- **추가 비용 0** — 구독 범위 내 음성. (별도 Realtime API·전용 앱은 불필요로 결론)
- 크롬 확장 프로그램도 만들지 않는다 — 관리 비용이 이득보다 크다. 네트워크 탭에서 대화 원본을 수동 복사하는 것으로 충분.

## 데이터 흐름 (사용자 부담 최소)

```
[모바일] ChatGPT 앱에서 프랑스어 음성 대화 (프로젝트 안, 한 세션 = 한 대화방)
      ↓
[PC] 같은 대화방을 chatgpt.com 에서 열기
      ↓
GET https://chatgpt.com/backend-api/conversation/{uuid}   ← 대화방 URL 끝의 uuid
  응답(JSON)을 네트워크 탭에서 복사
      ↓
[Claude Code] JSON을 주면 → transcript 복원 + 분석 + 카드/문서 갱신 + 커밋
```

- 사용자가 하는 일 = **음성 대화 + GET 응답 복사 붙여넣기**. 나머지는 Claude Code가 처리.
- 원본 JSON에는 인증 토큰·내부 상태·검색 노이즈가 섞여 있으므로, **저장소에는 학습에 필요한 정보(화자·발화·시각·voice_session_id)만 필터링해서** 저장한다. 원본 통째 커밋 금지.

## 데이터 계층

| 계층 | 내용 | 확보 |
|------|------|------|
| L0 | 실제 음성 파일 | ✗ (접근 불가 — 포기) |
| **L1** | **ChatGPT 음성 전사 원본(JSON→필터)** | **✓ (raw source of truth)** |
| L2 | 정리된 transcript (.md) | ✓ |
| L3 | 세션 분석·지표 | ✓ |
| L4 | 다음 세션 학습 계획 (`state/current.md`) | ✓ |

> L1을 원본으로 삼는다. 미래에 분석 기준이 바뀌어도 transcript를 다시 분석하면 **재현 가능**하다.
