# 말하기 채점표 (rubric) — 실시간 상호작용 + 명료도

> 작문 rubric([`../writing/rubric.md`](../writing/rubric.md))의 철학(준거참조·환경 고정·점수변동=능력변동)은 그대로, **항목만 말하기용으로 교체**.
> **발음·억양 정밀 채점은 하지 않는다** (STT 한계). 명료도는 "AI가 알아들었는가"로만 측정.

## 평가 환경 (표준화 — 매월 고정)

| 항목 | 고정값 |
|------|--------|
| 과제 | ① 일상 설명 2분 ② 경험 이야기 2분 ③ 의견 말하기 2분 + 예상 못 한 후속 질문 3개 |
| 형식 | ChatGPT 음성 대화, 도움 금지(평가 중엔 힌트·선택지 X) |
| 만점 | 24점 (6항목 × 4) |
| 변동 | 주제만 (`scenarios.md`에서 추출, 같은 주제 반복 금지) |

## 6항목 (24점)

### ① 과제 수행 (message) — 4점
| 점수 | 기준 |
|------|------|
| 4 | 질문에 맞는 내용을 충분히 전달, 과제 완수 |
| 3 | 대체로 전달, 일부 미흡 |
| 2 | 부분 전달, 단어 나열에 가까움 |
| 0~1 | 과제 수행 곤란 |

### ② 상호작용 (interaction) — 4점
| 점수 | 기준 |
|------|------|
| 4 | 질문을 한 번에 이해, 되묻기·확인 자연스러움, 후속 질문에 반응 |
| 3 | 대체로 이해, 가끔 재표현 필요 |
| 2 | 긴 질문 자주 놓침, 단답 위주 |
| 0~1 | 질문 이해 반복 실패 |

### ③ 유창성 (fluency) — 4점
| 점수 | 기준 |
|------|------|
| 4 | 멈춤 적고 2~3문장 연결, 자기수정 가능 |
| 3 | 한 문장 단위, 멈춤 있으나 회복 |
| 2 | 단어·짧은 구 위주, 잦은 멈춤 |
| 0~1 | 발화 지속 곤란 |

### ④ 어휘 (lexique) — 4점
| 점수 | 기준 |
|------|------|
| 4 | 필요한 단어·chunk를 제때 인출, 우회 설명 가능 |
| 3 | 기본 어휘로 수행, 인출 지연 일부 |
| 2 | 자주 막힘("le mot de…"), 영어 혼용 |
| 0~1 | 어휘 부족으로 수행 곤란 |

### ⑤ 문법 (morphosyntaxe) — 4점
| 점수 | 기준 |
|------|------|
| 4 | 기본 구조(인칭·시제·전치사) 대체로 정확, 복문 시도 |
| 3 | 기본 정확, 복잡 구조에서 오류 |
| 2 | 잦은 기본 오류(전치사·인칭·동사활용) |
| 0~1 | 문장 성립 어려움 |

### ⑥ 명료도 (intelligibility) — 4점
> 발음 품질이 아니라 **전달 성공률**. STT·소음·인식오류의 영향을 함께 받으므로 정밀 채점 아님.

| 점수 | 기준 |
|------|------|
| 4 | 대부분 한 번에 인식됨, 반복 요청 거의 없음 |
| 3 | 가끔 재시도 후 인식 |
| 2 | 자주 다른 단어로 인식/반복 필요 |
| 0~1 | 반복적으로 전달 실패 |

## 보조 지표 (근거 발화 기록) — 채점과 별도

작문 rubric의 "오류 횟수" 지표와 같은 취지. 점수보다 **관찰 가능한 행동**을 세션 로그에 남긴다.

- **질문 이해**: 첫 질문 이해 / 쉬운 재표현 후 이해 / 한국어 필요 / 실패 (각 횟수)
- **표현 산출도**: `I` 독립 / `H` 힌트 후 / `R` 모델 따라 / `F` 실패
- **대화 유지 전략 사용**: Pardon·Vous pouvez répéter·Je ne sais pas comment le dire 등 실제 사용 여부
- **발화 길이 분포**: 단어만 / 한 문장 / 2~3문장 / 30초+ / 1분+
- **STT 오인식 사례**: 어떤 단어가 반복 인식 실패했는지 (발음 명료도의 간접 신호)

> 근거 발화(evidence turn)를 함께 기록하면, 버즈챌린지 제출 시 "AI가 점수 올랐다고 말함"이 아니라 **실제 발화로 뒷받침**되는 향상을 보여줄 수 있다.

## 채점 절차 (관대 편향 방지)

작문에서 얻은 교훈 그대로:
1. **블라인드 채점**: 이전 점수·"이번엔 나았을 것" 배제, 원문 transcript + 이 rubric만으로 대조. 향상 비교는 채점 후에만.
2. **기본 vs 복잡 오류 구분**: 전치사(chez)·인칭 혼동·동사활용 누락은 **기본 오류**(⑤ 2점대).
3. **베이스라인 바닥효과**: 9월 첫 기준선은 실제보다 낮을 수 있음 → 다음 달 상승분 부풀림 주의. "조기 달성"은 성과가 아니라 재보정 신호.
