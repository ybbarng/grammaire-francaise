## 3. ⭐ 오늘 핵심 오류 — 조동사·avoir + 원형/과거분사
- **je pouvais le résolvais / je l'ai résolvais / le porte** ❌ → 둘째 동사를 활용형으로 씀.
- 규칙: **양태동사(pouvoir) 뒤=원형, avoir 뒤=과거분사.** résoudre 과거분사=**résolu**(≠반과거 résolvais).
- 즉시 재드릴: 처음 2회 실패(résolvais 재발) → résolu 형태 명시 학습 후 "Je l'ai déjà résolu / Nous avons résolu … ensemble" 정착. **T1 신규.**

## 5. 성장 vs 정체 (사용자 질문)
- ✅ 성장: COI lui(8/6 오류→오늘 je lui ai demandé 정착), **대과거 자발 사용**(j'avais appris/oublié), 성수일치·간접화법 안정.
- ⚠️ 정체(수렴 중): 조동사+원형 · après avoir p.p. · 동사+전치사 — 흩어진 실수가 **특정 카드로 좁혀지는 중**(진전 신호).
- 수준: 구성·서사 **B2** / 어휘 B1+~B2 / 정확도 **B1**.

## 6. ⭐ 첨삭 방침 확정 — 균형 교정
- 사용자 피드백: 초기 교정본이 **과교정**(원문도 맞는 표현까지 바꿈). → 최소본(❌만) → 균형본으로 재조정.
- **확정 기준**: ① 문법 오류(❌) + ② 문법은 맞지만 원어민이 잘 안 쓰는 표현(△) **둘 다 교정**, ③ **원문이 이미 자연스러우면 그대로 유지**(사용자 목소리 존중).
- 되살린 원문 표현: on n'avait besoin que de / il y avait / je pouvais le faire / je m'entraînais toujours / si je le portais 등.
- 반영한 △ 개선: faire ça→y arriver · portais→emportais · les mains occupées(손 이미지 유지) · les études de l'école→le travail scolaire.
